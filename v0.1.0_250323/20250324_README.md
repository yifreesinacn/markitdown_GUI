## 一、程序设计背景

微软发布了一个Markdown工具：[Markdown](https://github.com/microsoft/markitdown)， markitdown工具可以将PDF、PPT、Word、EXCEL、HTML等十几种格式转为Markdown格式。目前微软发布的MarkItDown版本是使用命令行方式进行转换，非常不方便。现在以markitdown为基础开发一个windows系统下的图形界面软件，可以直接通过窗口型操作将文件进行格式转换。

## 二、开发进展

使用python语言和tkinter框架开发一个可以在windows系统下使用的EXE应用，可以直接通过窗口界面的方式使用。目前项目已经基本完成。

- 使用环境：windows

- 开发语言：python

- 框架：tkinter

- 打包程序：pyinstaller

- 主文件：MarkItDown_GUI_v0.1.0a1.py；

- 打包脚本：MakeMD_build.py；

- 图标文件：icon.ico

## 三、主要功能

- 转换文件类型：WORD文档、EXCEL文档、PDF文档、HTML文档等

- 单文件转换

- 批量转换

- 单文件转换时可以预览转换后的文件

## 四、主要变化

- 1.修正了以前没有发现的问题，如doc文档不能转换等。

- 2.对于有图片的doc文档，能在目录文件夹内建立图片目录，将原文档中图片导出。

- 2.在配置框内对支持的文件类型进行说明。

- 3.修改了一些细节

## 五、存在的主要问题：

- 1.如果文档中有图片，转换后的MD文档中可能没有图片。

- 2.文件过大。

- 3.PDF格式支持不好

- 4.转换doc文档时会在工作目录产生一个同名docx文档。

- 4.仍有部分格式不支持，未完全测试
