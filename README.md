# markitdown_GUI
基于微软MarkItDown工具开发的图形界面应用程序，用于将各种文档格式转换为Markdown格式。
## 功能特点

- 支持多种文件格式转换：
  - PDF文档
  - Word文档（.docx）
  - Excel文档（.xlsx）
  - PowerPoint文档（.pptx）
  - 图片文件（.png, .jpg, .jpeg）
  - 音频文件（.mp3, .wav）
  - HTML文件
  - 文本文件（.csv, .json, .xml）
  - 压缩文件（.zip）

- 转换功能：
  - 单文件转换
  - 批量转换
  - 实时预览
  - 自定义输出目录

- 用户界面：
  - 简洁直观的图形界面
  - 转换进度显示
  - 结果预览
  - 批量处理

## 系统要求

- Windows 10或更高版本
- Python 3.8或更高版本
- 依赖库：
  - markitdown
  - python-docx
  - pdfminer.six
  - Pillow
  - pywin32
